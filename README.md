# ⚡ كودسيبر | CodeSiber

تطبيق ويب تفاعلي حي (Real-Time Multiplayer Web App) للعبة الشِّفرة والجواسيس الجماعية باللغة العربية، مصمم بأجواء سيبرانية عصرية (Cyberpunk / Dark Theme) وبأعلى سرعة استجابة عبر البث الحي للأحداث.

---

## 🚀 مميزات لعبة كودسيبر (Features)
* **لعب جماعي حي وسريع:** استخدام تقنية Socket.io للربط الفوري بين جميع اللاعبين والتحديث التلقائي لحالة الغرفة.
* **تفاعلات إيموجي حية:** إمكانية إرسال إيموجيات تفاعلية عائمة (🔥, 🤦‍♂️, 💀) تنبثق فوق البطاقات فور التخمين.
* **بنك كلمات عربي ضخم:** دعم قاعدة بيانات شاملة للكلمات العربية المتنوعة.
* **تصميم سيبراني متجاوب:** واجهة مُحسّنة بالكامل لشاشات الهواتف الذكية والأجهزة المختلفة بدعم الحواف الآمنة للآيفون والأندرويد.

---

## 🛠️ البنية البرمجية (Tech Stack)
* **Backend:** Node.js / Express.js
* **Real-time Engine:** Socket.io
* **Data Storage:** JSON Word Bank (`words-bank.json`)
* **Frontend:** HTML5, Modern CSS3, JavaScript (Vanilla ES6)
